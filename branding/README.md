# CHRONOVAULT branding

The product mark is a **temporal vault**: a chrono-clock inside a vault ring.

## Assets

| File | Purpose |
| --- | --- |
| `chronovault-mark.svg` | Master brand mark (64×64, favicon-grade, cyan → magenta gradient) |
| `chronovault-mark-128.png` | Representative raster (128×128) for stores/docs |
| `chronovault-icon.svg` | Same vector source as the web favicon |

The same SVG source is embedded in the product:

- web favicon: `cli/src/main/resources/web/icon.svg` (served at `/favicon.ico`)
- mark in the dashboard topbar: inline `<svg>` in `index.html`
